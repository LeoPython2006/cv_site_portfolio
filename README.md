## Overview

A static, responsive portfolio website created to present an early CV, selected projects, education, and contact information. It includes animated hero text, a project carousel, a timeline layout, and light/dark color mode.

## Run locally

No build step is required.

~~~bash
python -m http.server 8000
~~~

Then open [http://localhost:8000](http://localhost:8000).

## Structure

| Path | Purpose |
|---|---|
| **index.html** | Main portfolio content |
| **css/** | Bootstrap, carousel, icons, and custom styles |
| **js/** | Interactions and carousel behavior |
| **images** | Profile and project media |
